อ่านรูปคำสั่งหุ้นสหรัฐด้วย AI

อัปโหลดรูปรายละเอียดคำสั่ง

เลือกได้หลายรูป (1 รูป = 1 คำสั่งซื้อ/ขาย · ถ้าคำสั่งเดียวยาวเกินหน้าจอ แคปมา 2 รูปได้) ผลที่อ่านได้จะแสดงให้ตรวจ/แก้ไขในหน้านี้ แล้วส่งกลับไปกรอกฟอร์ม "🇺🇸 สหรัฐ" — ยังไม่บันทึกอัตโนมัติ ต้องกดบันทึกในฟอร์มเอง · รองรับเฉพาะหุ้นสหรัฐ (USD)

หน้านี้ไม่ได้ถูกเปิดจากปุ่มในฟอร์ม "🇺🇸 สหรัฐ" จึงใช้อ่านรูปทดสอบได้ แต่ส่งผลกลับไปฟอร์มไม่ได้ (คัดลอกผลเป็น JSON ได้แทน)
ยังไม่มีคีย์? ขอฟรีที่ aistudio.google.com/apikey (ล็อกอิน Gmail แล้วกด Create API Key)
คีย์เก็บใน localStorage ของเบราว์เซอร์เครื่องนี้เท่านั้น ไม่ส่งไปที่อื่นนอกจาก Google
